## 🧠 Problem-Solving Approach

For every important problem, I try to follow this process:

```text
1. Understand the problem
        ↓
2. Identify the pattern
        ↓
3. Think of a brute-force solution
        ↓
4. Optimize the approach
        ↓
5. Implement in Java
        ↓
6. Analyze Time Complexity
        ↓
7. Analyze Space Complexity
        ↓
8. Test with different cases
        ↓
9. Revise the problem
```
